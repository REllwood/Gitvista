# Code of conduct

GitVista is built for people who are new to Git, so many questions here come from beginners. Everyone who takes part in the project's issues, pull requests and other spaces is expected to follow this code.

## Expected behaviour

- Answer beginner questions patiently, and explain the Git terms you use.
- Criticise code and ideas, not the people who wrote them.
- Assume good intent, and ask questions before deciding that someone is wrong.
- Accept a maintainer's decision on a pull request or issue, even when you disagree with it.

## Unacceptable behaviour

- Insults, personal attacks or deliberately demeaning comments
- Harassment, including repeated unwanted contact
- Discriminatory jokes or language about anyone's identity
- Sexual language or imagery
- Threats of violence
- Publishing someone's private information without their permission

## Reporting

Report a comment, issue or pull request with the **Report content** option in its menu on GitHub. Reports are handled privately.

## Enforcement

The maintainer may edit or delete comments, lock a conversation, or block a person from the project. A first minor problem usually gets a private warning. Harassment, threats and publishing private information lead to an immediate block.
